\section{Conclusion}

The thesis implemented an intent-aware profile and image recommendation workflow for JupyterHub. It extracts structured workload intent, retrieves catalog candidates through sparse and dense channels, applies deterministic hard constraints, and presents the result for user review and confirmation. The administrator-managed catalog and pre-spawn validation keep deployment choices within approved profiles and digest-pinned images.

E1 evaluated recommendation quality on the newly compiled Benchmark v1 held-out test split (471 cases across 157 disjoint families with empirical Linux cgroups v2 ground truth). In multi-candidate discovery, P2 Local achieved 73.46\% Candidate Accuracy@3 and 81.32\% Profile Accuracy@3 (+47.13\% gain over rule-based P1) with an offline execution latency of 2.28\,ms. In single-turn precision, P2 LLM Mode achieved the highest Candidate Accuracy@1 (27.39\%) and Profile Accuracy@1 (35.03\%), reaching 79.19\% JointAccept@1 while cutting resource over-provisioning to 58.60\%. In domain-specific machine learning workloads (PyTorch, TensorFlow, scikit-learn), P2 demonstrated consistent candidate discrimination whereas rule heuristics failed completely (0.0\%). In Stream E2, linguistic robustness evaluation across 471 prompt variants revealed high cross-lingual invariance ($|\Delta| \le 1.28\%$ for P2 Local and $|\Delta| \le 2.55\%$ for P2 LLM) across Canonical English, Informal/Noisy text, and localized Vietnamese queries.

In Stream E4, kernel resource profiling across 800 physical Pod trials on OrbStack confirmed that calibrated safe envelopes completely avoided out-of-memory terminations under normal operating envelopes (P2 Catalog achieving 100.0\% success, and P2 Dynamic saving 49.3\% memory at 95.0\% success), with deterministic packing demonstrating a 50.0\% reduction in worker node requirements. Furthermore, a 50-node cluster simulation driven by empirical Alibaba PAI GPU cluster trace timing proxies across 30 seeds (24,000 sessions) demonstrated that P2 eliminated pending admission queues (reducing mean wait from 13.99 minutes to zero, and P95 wait from 28.25 minutes to zero) and prevented GPU monopolization (0.00\% stranding), reaching 143.5 peak concurrency (1.44$\times$ over B0) and unlocking a 5.56$\times$ theoretical multi-tenancy capacity multiplier. In Stream E5, all 76 eligible container functional probes passed successfully (100\%), and OCI image manifest analysis across catalog scales of 4, 8, and 16 images verified monotonically increasing deduplication savings from 27.61\% (2.93 GiB) up to 30.55\% (5.34 GiB) and 37.06\% (12.48 GiB saved).

\section{Future work}

The experimental results are subject to several limitations. The evaluation is based on a controlled resource and image catalog and therefore does not cover the full diversity of workloads, arbitrary bare-metal Kubernetes clusters, and bespoke software stacks. Future work can extend the evaluation to larger and more heterogeneous catalogs, additional specialized workload domains, and interactive human usability studies with live user cohorts. Historical workload telemetry could also be incorporated into continuous feedback loops to dynamically tune resource envelopes based on previously observed runtime behavior. Language-model-based re-ranking could also be explored as an optional refinement stage, provided that its latency overhead and accuracy benefits are systematically evaluated against tight real-time budget requirements.
