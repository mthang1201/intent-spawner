\section{Conclusion}

The experimental evaluation examined the proposed approach from several complementary perspectives, including recommendation quality, robustness to different workload descriptions, user interaction, resource efficiency, and notebook image functionality. The recommendation experiments evaluated whether the selected resource profile and notebook image jointly satisfied the requirements expressed in the user's workload intent. The evaluation used a predefined catalog and deterministic acceptance criteria, allowing recommendation quality to be assessed independently of the execution environment. The experiments also examined different retrieval configurations to evaluate how lexical and semantic matching contribute to intent-based resource and image selection. The results of the recommendation evaluation indicate that combining lexical and semantic retrieval provides a practical basis for matching natural-language workload descriptions against the available resource and image catalog. Lexical retrieval preserves matches based on explicit technical terminology, while semantic retrieval provides additional robustness when users describe similar requirements using different wording. Their combination therefore addresses complementary aspects of intent matching rather than relying on a single retrieval mechanism.

The user evaluation further examined the practical interaction cost of using intent-based recommendation compared with conventional profile selection. Selection success and decision time were measured using participant-level analysis, while subjective feedback was used as additional evidence about the interaction. This evaluation provides an empirical assessment of whether recommendation can reduce the effort required to identify an appropriate configuration while preserving the user's ability to review and select the proposed configuration. Resource-efficiency experiments evaluated the computational cost associated with recommendation and resource allocation. The evaluation considered both CPU and memory consumption and related these costs to successful workload completion. Different allocation strategies were compared under controlled workload families, allowing the overhead of the proposed approach to be considered separately from workload-specific variation. The image-related experiments evaluated whether recommended notebook images were operationally suitable rather than treating image selection as a purely semantic matching problem. An image was considered functionally successful only when it satisfied the required deterministic probes. The storage evaluation additionally distinguished logical image size from unique content-addressed layer storage, making it possible to measure the effect of shared image layers as the catalog was expanded. Overall, the experiments provide evidence that intent-based recommendation can be evaluated as a combination of semantic matching, deterministic constraint satisfaction, user interaction, resource consumption, and image functionality. A semantically plausible recommendation alone is therefore not sufficient for a Kubernetes-based computational environment; the resulting configuration must also be operationally usable and compatible with the available resources and images.

\section{Future work}

The experimental results are subject to several limitations. The evaluation is based on a controlled resource and image catalog and therefore does not cover the full diversity of workloads, Kubernetes clusters, and software environments encountered in production. User-study results are also influenced by the participant population and experimental procedure. In addition, image functionality depends on the specific images and probe requirements included in the evaluation. Future work can extend the evaluation to larger and more heterogeneous catalogs, additional workload domains, and longer-term user studies. Historical workload information could also be incorporated to improve recommendations based on previously observed resource usage. Further work on retrieval and ranking could investigate how recommendation quality changes as the catalog becomes larger and more diverse. Language-model-based re-ranking could also be explored as an optional additional stage after retrieval, provided that its computational cost and effect on recommendation quality are evaluated systematically. Finally, runtime resource measurements could be used to calibrate recommended resource allocations against actual workload behavior.
