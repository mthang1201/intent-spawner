\addcontentsline{toc}{chapter}{Abstract}
\begin{preamble}{Abstract}
Shared JupyterHub deployments require users to translate semantic workload requirements into container images and Kubernetes resource specifications before pod creation. This thesis presents Intent-Spawner, a bounded pre-spawn decision-support system for environment selection. Its primary method, P2, extracts structured constraints from natural-language intent, retrieves administrator-curated candidates via hybrid BM25 and dense retrieval with Reciprocal Rank Fusion, removes candidates violating hard constraints, and ranks feasible options deterministically. An interactive preview and single-use token bind the user's explicit confirmation to the pre-spawn hook without recomputation.

The system is evaluated under Protocol-v5 across offline recommendation quality and prompt robustness (E1/E2), human outcomes (E3), local resource envelopes (E4), and OCI image capability and layer reuse (E5). Empirical evidence includes development observations across 18 workload families, 421 local Pod trials, and four digest-pinned images. E3 contains no participant data, and formal confirmatory hypotheses remain unexecuted. The primary contribution is an auditable architecture and reproducible protocol for pre-spawn intent resolution that enforces strict evidence boundaries without overclaiming general cluster efficiency or production readiness.

\textbf{Keywords:} JupyterHub; Kubernetes; workload intent; hybrid retrieval.
\end{preamble}
